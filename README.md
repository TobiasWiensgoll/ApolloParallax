# ApolloParallax

## Description

Parallax Website Projekt über die erste Mondlandung

## Installation

Branch DEVELOP im Browser öffnen auf CODE klicken und VSCODE HTTPS auswählen und Lokal dadurch klonen

## Usage

Wir arbeiten IN DEVELOP
Git pull "aus der Cloud" um immer Up to Date zu sein --> Git Commit um seinen Fortschritt mit einem Comment zu speichern, Git Push in die Cloud
Bei Meilensteine Merged Tobias die Branches in Main
